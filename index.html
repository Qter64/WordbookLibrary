Как пользоваться

📥

Добавление + OCR

Выберите PDF. ИИ определит метаданные, OCR распознает первые 3 страницы для умного поиска.

🔍

Умный поиск

Ищет по названию, автору И содержимому учебника. Напишите «производная» — найдутся книги с этим термином.

🤖

ИИ-помощник

Робот слева внизу. Отвечает на вопросы по школьным темам и ищет информацию в текстах учебников.

📁

Папка

Подключите папку «Учебники» — новые файлы копируются туда автоматически.

💾

Резервная копия

«Экспорт» сохраняет всю библиотеку с OCR-текстами. «Импорт» восстанавливает на другом устройстве.
